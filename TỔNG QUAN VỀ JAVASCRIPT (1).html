Tài Liệu & Bài Tập JavaScript DOM

Tổng hợp lý thuyết toàn diện, ví dụ minh họa và bài tập thực hành tương tác

Phần 1: JavaScript Trong Thiết Kế Web

JavaScript (JS) là một trong ba ngôn ngữ cốt lõi của phát triển web, bên cạnh HTML (xây dựng cấu trúc) và CSS (định hình giao diện). Nếu HTML là khung xương và CSS là lớp áo, thì JavaScript chính là hệ thần kinh giúp website hoạt động tương tác và linh hoạt.

1. Vai trò của JavaScript

JavaScript biến các trang web tĩnh (static) thành các ứng dụng web động (dynamic) nhờ các khả năng:

  • Tạo tương tác với người dùng: Xử lý sự kiện khi người dùng nhấp chuột (click), di chuyển chuột (hover), cuộn trang (scroll), hoặc gõ phím.
  • Thao tác với DOM (Document Object Model): Thay đổi nội dung, cấu trúc và kiểu dáng CSS của trang web ngay lập tức mà không cần tải lại trang.
  • Xử lý biểu mẫu (Form Validation): Kiểm tra dữ liệu người dùng nhập (như định dạng email, độ dài mật khẩu) trước khi gửi về máy chủ (server).
  • Giao tiếp bất đồng bộ (AJAX & Fetch API): Gửi và nhận dữ liệu từ server ngầm mà không làm gián đoạn trải nghiệm trên trang.
  • Hiệu ứng & Hoạt ảnh: Tạo menu thả xuống, slider ảnh, popup modal, hoạt ảnh chuyển động mượt mà.

2. Cách tích hợp JavaScript vào trang Web

Có 3 cách chính để chèn code JavaScript vào tệp HTML:

A. Inline JavaScript (Viết trực tiếp trong thẻ HTML)

Gắn trực tiếp vào thuộc tính sự kiện của thẻ HTML.

<button onclick="alert('Xin chào!')">Bấm vào đây</button>

B. Internal JavaScript (Thẻ <script> trong tệp HTML)

Viết code JS bên trong thẻ <script> đặt ở thẻ <head> hoặc trước thẻ đóng </body>.

<!DOCTYPE html>
<html>
<head>
    <title>Ví dụ JS Internal</title>
</head>
<body>
    <h1 id="title">Nội dung ban đầu</h1>
    <button onclick="changeText()">Đổi nội dung</button>

    <script>
        function changeText() {
            document.getElementById("title").innerText = "Nội dung đã được thay đổi!";
        }
    </script>
</body>
</html>

C. External JavaScript (Tệp .js riêng biệt - Khuyên dùng)

Tách riêng code JS ra một tệp độc lập (ví dụ: script.js) và liên kết vào HTML.

Tệp index.html:

<!DOCTYPE html>
<html>
<head>
    <title>Ví dụ JS External</title>
</head>
<body>
    <button id="btn">Click me</button>
    
    <!-- Nhúng tệp JS bên ngoài -->
    <script src="script.js"></script>
</body>
</html>

Tệp script.js:

document.getElementById("btn").addEventListener("click", function() {
    alert("Bạn đã nhấp vào nút!");
});

Loại Tên công cụ Mục đích sử dụng

4. Lợi ích khi sử dụng JavaScript

  1. Cải thiện trải nghiệm người dùng (UX): Phản hồi tức thì với các thao tác của người dùng.
  2. Giảm tải cho Server: Kiểm tra và xử lý dữ liệu ngay tại phía trình duyệt (client-side).
  3. Đa năng: Sử dụng ở cả Front-end, Back-end (Node.js), Di động (React Native), và Desktop (Electron).

Phần 2: Khung Chương Trình & Ví Dụ Code JS DOM

1. Giới thiệu tổng quan về DOM

  • Khái niệm DOM: Là gì? Tại sao JS cần DOM để tương tác với HTML/CSS.
  • Cấu trúc cây DOM (DOM Tree): Cấu trúc dạng cây với các Nodes, Elements, Attributes, Text.
  • Đường đi của dữ liệu: Mô hình Request → HTML/CSS → DOM Tree → Render.
// Xem toàn bộ cây DOM của trang web
console.log(document);

// Lấy thông tin các phần tử gốc
console.log(document.documentElement); // <html>
console.log(document.head);            // <head>
console.log(document.body);            // <body>

2. Truy vấn & Chọn phần tử (Selecting Elements)

  • Phương thức hiện đại: querySelector() và querySelectorAll().
  • Phương thức truyền thống: getElementById(), getElementsByClassName().
  • So sánh: NodeList (Static) vs HTMLCollection (Live).
// 1. Chọn 1 phần tử đầu tiên
const heading = document.querySelector('#main-title');
const submitBtn = document.querySelector('.btn-primary');

// 2. Chọn TẤT CẢ phần tử khớp điều kiện (NodeList)
const menuItems = document.querySelectorAll('.nav-item');

menuItems.forEach((item, index) => {
  console.log(`Mục thứ ${index + 1}:`, item);
});

// 3. Phương thức truyền thống
const header = document.getElementById('header');
const cards = document.getElementsByClassName('card'); // Trả về HTMLCollection

3. Thay đổi nội dung & Thuộc tính (Content & Attributes)

  • Nội dung: Phân biệt textContent, innerText, và innerHTML (Cảnh báo XSS).
  • Thuộc tính: getAttribute(), setAttribute(), removeAttribute().
  • Data Attributes: Đọc và ghi dữ liệu tùy chỉnh qua element.dataset.*.
const box = document.querySelector('#box');
const link = document.querySelector('#my-link');

// 1. Thay đổi nội dung
box.textContent = 'Nội dung chữ mới (An toàn)';
box.innerHTML = '<strong>Chữ đậm mới</strong>';

// 2. Thay đổi thuộc tính (Attribute)
link.setAttribute('href', 'https://google.com');
link.setAttribute('target', '_blank');

// 3. Thao tác với Data Attribute (data-*)
const userDiv = document.querySelector('#user');
console.log(userDiv.dataset.userId); // "102"
userDiv.dataset.role = 'editor';      // Cập nhật giá trị data-role

4. Thay đổi Giao diện / CSS (Styling & Classes)

  • Inline Style: Cú pháp element.style.propertyName.
  • Quản lý Class: classList.add(), remove(), toggle(), contains().
const card = document.querySelector('.card');

// 1. Thay đổi Inline Style trực tiếp
card.style.backgroundColor = 'lightgray';
card.style.padding = '20px';
card.style.borderRadius = '8px';

// 2. Quản lý Class (Khuyên dùng)
card.classList.add('active', 'shadow');
card.classList.remove('active');

// Bật/Tắt class (Rất hay dùng cho Dark Mode, Toggle Menu)
card.classList.toggle('dark-mode');

// Kiểm tra sự tồn tại của class
if (card.classList.contains('dark-mode')) {
  console.log('Đang ở chế độ Dark Mode');
}

5. Xử lý Sự kiện (Event Handling)

  • Lắng nghe sự kiện: addEventListener(event, callback).
  • Sự kiện phổ biến: Mouse, Keyboard, Form Input, Window events.
  • Event Object: Phân biệt e.target, e.preventDefault(), e.stopPropagation().
const btn = document.querySelector('#submit-btn');
const form = document.querySelector('#login-form');

// 1. Sự kiện Click
btn.addEventListener('click', function(e) {
  console.log('Người dùng vừa bấm nút!');
  console.log('Thẻ được bấm là:', e.target);
});

// 2. Sự kiện Form Submit (Chặn reload trang)
form.addEventListener('submit', function(e) {
  e.preventDefault();
  const usernameInput = document.querySelector('#username');
  console.log('Tên đăng nhập:', usernameInput.value);
});

// 3. Sự kiện gõ phím (Keyboard)
document.addEventListener('keydown', function(e) {
  if (e.key === 'Escape') {
    console.log('Người dùng vừa bấm phím Esc');
  }
});

6. Tạo, Thêm, Xóa phần tử (DOM Manipulation)

  • Tạo phần tử: document.createElement().
  • Thêm vào cây DOM: appendChild(), prepend(), insertAdjacentHTML().
  • Xóa phần tử: element.remove() hoặc removeChild().
// 1. Tạo phần tử <li> mới
const newItem = document.createElement('li');
newItem.textContent = 'Học JavaScript DOM';
newItem.classList.add('item');

// 2. Thêm vào thẻ cha <ul>
const list = document.querySelector('#todo-list');
list.appendChild(newItem); // Thêm vào cuối
list.prepend(newItem);   // Thêm vào đầu

// 3. Thêm nhanh bằng chuỗi HTML
list.insertAdjacentHTML('beforeend', '<li class="item">Bảo vệ đồ án</li>');

// 4. Xóa phần tử
const oldItem = document.querySelector('.old-item');
if (oldItem) oldItem.remove();

7. Duyệt cây DOM (DOM Traversal)

  • Đi lên: parentElement, closest(selector).
  • Đi xuống: children, firstElementChild, lastElementChild.
  • Đi sang ngang: nextElementSibling, previousElementSibling.
const currentCard = document.querySelector('.card-active');

// 1. Đi lên (Cha hoặc phần tử tổ tiên gần nhất)
const parentSection = currentCard.parentElement;
const closestWrapper = currentCard.closest('.container');

// 2. Đi xuống (Các thẻ con)
const cardChildren = currentCard.children;
const firstTitle = currentCard.firstElementChild;

// 3. Đi sang ngang (Anh / Em cùng cấp)
const nextCard = currentCard.nextElementSibling;
const prevCard = currentCard.previousElementSibling;

DOM (Document Object Model) là mô hình đối tượng tài liệu dạng cây đại diện cho HTML.
