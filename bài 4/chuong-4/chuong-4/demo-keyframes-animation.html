@keyframes và thuộc tính animation

Demo thực hành — Chương 4, phần 3 (b)

1. Cú pháp @keyframes

Gồm hai bước: khai báo kịch bản bằng @keyframes, rồi gán kịch bản đó cho phần tử bằng animation.

/* Bước 1 — mô tả hiệu ứng diễn ra như thế nào */
@keyframes nhay-len{
  0%  { transform: translateY(0); }
  40% { transform: translateY(-38px); }
  100%{ transform: translateY(0); }
}

/* Hoặc viết gọn khi chỉ có hai mốc */
@keyframes hien-dan{
  from{ opacity: 0; }
  to  { opacity: 1; }
}

/* Bước 2 — gán cho phần tử */
.vuong{
  animation: nhay-len 1.4s ease-in-out infinite;
}

Bấm ô Tạm dừng tất cả hiệu ứng trên thanh đen để "đóng băng" mọi thứ. Đó chính là thuộc tính animation-play-state: paused.

2. Tám thuộc tính của animation

Thuộc tính Nghĩa là Giá trị hay dùng
animation-name Tên kịch bản @keyframes nhay-len
animation-duration Chạy trong bao lâu 1.4s
animation-timing-function Nhịp nhanh chậm ease, linear
animation-delay Chờ bao lâu rồi mới chạy .3s
animation-iteration-count Lặp mấy lần 1, 3, infinite
animation-direction Chạy xuôi hay quay ngược normal, alternate, reverse
animation-fill-mode Giữ trạng thái đầu / cuối forwards, backwards, both
animation-play-state Đang chạy hay tạm dừng running, paused 
/* Viết gọn — đúng thứ tự: name duration timing delay count direction fill */
animation: nhay-len 1.4s ease-in-out .2s infinite alternate forwards;

Quan sát khác biệt

direction: normal
direction: alternate
direction: reverse
delay: 1.2s
iteration-count: 2
1 lần + fill-mode: forwards
fill-mode: forwards rất quan trọng. Không có nó, phần tử chạy xong sẽ nhảy về trạng thái ban đầu — hai dòng cuối cho thấy rõ điều này: dòng "2 lần" quay về vạch xuất phát, dòng "forwards" đứng lại ở đích.

5. Transition hay Animation?

  Transition Animation (@keyframes)
Khi nào chạy Phải có tác động: hover, focus, đổi class Tự chạy ngay khi tải trang
Số mốc Chỉ 2: đầu và cuối Bao nhiêu mốc tùy ý (0% → 100%)
Lặp lại Không lặp được Lặp bao nhiêu lần cũng được
Tạm dừng Không Được, bằng animation-play-state
Hợp với Nút bấm, thẻ, menu, ô nhập Vòng quay tải, banner, hiệu ứng vào trang
Cách nhớ: có người chạm vào mới chạy → dùng transition. Tự chạy hoặc chạy lặp lại → dùng animation.

Bài tập tại lớp

  1. Viết @keyframes tên rung-lac làm nút bấm lắc qua lại khi tải trang.
  2. Đổi vòng quay tải thành hai cạnh được tô màu (border-top-color và border-left-color).
  3. Thêm phần tử thứ 6 và 7 vào danh sách chạy lần lượt, tính đúng độ trễ.
  4. Mở F12 → Elements → Styles, tìm dòng animation-duration của spinner và sửa thành 5s để xem nó quay chậm lại.
