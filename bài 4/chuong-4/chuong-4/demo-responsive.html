CSS Responsive & Media Query

1. Cú pháp Media Query

/* Áp dụng KHI màn hình rộng TỪ 768px trở lên */
@media (min-width: 768px){
  .luoi-sp{ grid-template-columns: repeat(3, 1fr); }
}

/* Áp dụng KHI màn hình rộng TỐI ĐA 640px */
@media (max-width: 640px){
  .menu ul{ flex-direction: column; }
}

/* Kết hợp hai điều kiện */
@media (min-width: 768px) and (max-width: 991px){ ... }

Các breakpoint thông dụng

Breakpoint Thiết bị Bố cục gợi ý
< 576px Điện thoại dọc 1 cột
≥ 576px Điện thoại ngang 2 cột
≥ 768px Máy tính bảng 3 cột, menu nằm ngang
≥ 992px Laptop 4 cột, hiện sidebar
≥ 1200px Màn hình lớn Giới hạn bề rộng nội dung

2. Đơn vị co giãn và hàm clamp()

Dòng chữ dưới đây không dùng media query nào cả — nó tự lớn nhỏ theo bề rộng cửa sổ, nhưng không bao giờ nhỏ hơn 22px và không bao giờ lớn hơn 44px.

Chữ tự co giãn mượt mà

h2{ font-size: clamp(22px, 5vw, 44px); }
           nhỏ nhất ─┘   ┌─ mong muốn   └─ lớn nhất */
Đơn vị Nghĩa là Hay dùng cho
% Phần trăm của thẻ cha Chiều rộng khối
vw / vh 1% bề rộng / chiều cao màn hình Ảnh bìa, tiêu đề lớn
rem Nhân với cỡ chữ gốc (thường 16px) Cỡ chữ, khoảng cách
clamp() Chặn giá trị trong khoảng nhỏ nhất – lớn nhất Cỡ chữ co giãn
min() / max() Lấy giá trị nhỏ hơn / lớn hơn width:min(100%, 1080px)

7. Kiểm tra giao diện bằng DevTools

Thao tác Làm gì
F12 Mở DevTools
Ctrl + Shift + M Bật / tắt chế độ xem điện thoại (Device Toolbar)
Dimensions Chọn sẵn iPhone, iPad, Galaxy… hoặc chọn Responsive để tự kéo
Zoom Chọn Fit to window nếu khung xem bị tràn ra ngoài
Biểu tượng xoay Đổi giữa màn hình dọc và ngang
Throttling Giả lập mạng chậm 3G để xem trang tải lâu cỡ nào
Ctrl + Shift + P Gõ screenshot để chụp ảnh toàn trang
Mẹo: kéo chậm thanh bề rộng ở chế độ Responsive và quan sát con số hiện phía trên. Tới đúng 576 / 768 / 992 / 1200 bạn sẽ thấy bố cục "nhảy" một nhịp — đó là lúc media query có hiệu lực. Ô đen ở góc phải dưới trang này cũng đổi chữ theo.
Sai lầm thường gặp: quên thẻ <meta name="viewport">. Thử xóa dòng đó trong F12 → Elements rồi tải lại trang bằng điện thoại — mọi media query lập tức mất tác dụng.

Bài tập tại lớp

  1. Đổi các mốc breakpoint của lưới sản phẩm từ 576/768/992 sang 500/700/900 rồi quan sát điểm "nhảy" bố cục dịch chuyển.
  2. Viết lại lưới sản phẩm theo kiểu desktop-first (dùng max-width) và so sánh xem cách nào ngắn hơn.
  3. Thêm một breakpoint mới ở 1400px cho lưới hiển thị 5 cột.
  4. Dùng DevTools chọn thiết bị iPhone SE và kiểm tra trang không bị cuộn ngang.
